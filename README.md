# 高塔档案馆

`wiki/` 是 Sovereign Tower 的 React + Vite 中文剧情路线档案，使用 Vite 开发服务器和静态构建产物运行。

## 使用

在 `wiki/` 目录执行 `npm install` 后，使用 `npm run dev` 启动开发服务器，再通过终端输出的 `http://localhost:5173` 地址访问。生产构建使用 `npm run build`，产物位于 `dist/`。不要直接双击 `index.html`，浏览器会限制 `file://` 模块和资源请求。

也可以直接双击仓库根目录的 `启动Wiki.bat`，脚本会自动检查依赖、启动 Vite 并打开浏览器。

## 更新剧情数据

剧情关系阅读器使用 `Decompiled/` 中的完整中文编译 Ink、觐见、好感对话、骑士会话资源，以及 FutureSight 实机日志生成结构化数据：

```powershell
cd wiki
npm run data:story
```

生成结果写入 `wiki/src/data/storyGraph.json`。生成器使用 `inkjs` 实际执行完整编译 Ink，按到达关系生成君王选项和后续对白；FutureSight 实机日志补充条件与游戏效果。资金、满意度、属性、好感、恋爱值、任务、装备等实际状态变化会显示，切换表情等表现指令会过滤。格温丹好感剧情作为自动回归基准，顺序或选项不一致时生成会直接失败。

## 内容与来源

- `src/main.jsx`：仅加载剧情路线阅读器，不再包含其他 Wiki 分类和外层导航。
- `src/components/StoryExplorer.jsx`：剧情目录、关系画布、分支详情和历史对话阅读器。
- 剧情目录按游戏 `CharacterManager` 的骑士资源顺序聚合为两级树，入口默认展示“全部入口”；左右详情区域分别独立滚动。
- 对话正文开头展示入口出现条件；需要全知知识并回溯的特殊选项使用紫色标记，并在选项后追加知识提示。左侧搜索支持每条剧情中的对白、选项、条件和结果。
- 对没有显式 Ink 标签但由全知全能补丁揭示的条件失败选项，显示通用“须获得相关信息后回溯”提示。
- 对话阅读器默认占满人物树之外的空间，可切换为关系图分栏或完全隐藏；阅读设置默认收起，字体大小、段落间距和连续对白合并配置会保存在浏览器中。
- `src/data/storyGraph.json`：静态资源与 FutureSight 实机记录生成的剧情关系数据。
- `../docs/Wiki设计逻辑.md`：当前 Wiki 信息架构、剧情流归并、中文名与立绘规则；每版设计调整必须同步维护。
- `src/generatedResources.js`：由游戏资源目录生成的完整静态资源索引。
- `styles.css`：响应式视觉界面，支持移动端和深色显示模式。
- `public/assets/`：从 `Decompiled/graphics/` 复制的游戏原始 Logo、角色肖像、棋子、地图插图、地点纹章和装备图标。
- 每条档案都尽量保留 `source` 字段。代码中明确存在的内容标记为资源考据；无法从 `.tres` 或 Ink 导入文件直接确认的具体数值不在本版臆测。

## 维护边界

`Decompiled/` 仅作为阅读和定位资料，不属于 Wiki 运行时依赖。更新图片时重新从原始游戏资料复制到 `assets/`，不要让网页引用仓库外路径。
